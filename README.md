 # Advanced Sales Dashboard 

An interactive **Sales Analytics Dashboard built in Microsoft Excel** to monitor sales performance across distributors, products, and months.

The dashboard follows a modern dark green visual style and is designed to turn sales data into a compact management view with interactive filtering, KPI cards, trend analysis, comparisons, and detailed product/distributor breakdowns.

## Dashboard Preview

![Sales Dashboard Preview](dashboard_pro_preview3.png)

## Project Overview

This project transforms sales data into an interactive Excel dashboard for quickly answering questions such as:

* How much are we selling?
* How many units and transactions are being recorded?
* Which distributor contributes the most sales?
* Which products generate the highest sales?
* How are sales changing month by month?
* Which months or product/distributor combinations require attention?

The dashboard reference contains **5 distributors, 10 products, and 4,900 transactions** for 2025.

## Key KPIs

The dashboard includes dynamic KPI cards for:

* **Total Sales**
* **Units Sold**
* **Transactions**
* **Average Order Value**
* **Latest Month-over-Month (MoM) Growth**

## Visualizations

### Monthly Sales Trend

A line chart tracks sales performance across the 12 months of 2025, making overall trends and month-to-month movement easier to identify.

### Sales by Distributor

A doughnut chart compares the sales contribution of the five distributors.

### Sales by Product

A bar chart compares sales across the ten products and highlights the products generating the highest sales.

### Key Insights

A dedicated insights section summarizes important observations such as the top product, top distributor, best month, weakest month, and the contribution of the top three products.

### Distributor × Product Heatmap

A heatmap provides a detailed view of sales performance for every distributor-product combination.

## Interactive Filters

The dashboard supports interactive filtering by:

* **Distributor**
* **Product**
* **Month**
* **Reset** to return to the full dataset view

The KPI cards and visualizations recalculate based on the selected filters.

## How to Use

1. Download `Advanced_Sales_Dashboard_Professional.xlsx`.
2. Open the file in Microsoft Excel.
3. Use the distributor, product, and month filters to explore the dashboard.
4. Review the KPI cards and charts to analyze performance under each selection.
5. Use the heatmap for a more detailed distributor-product comparison.

## Project Goal

The goal of this project is to demonstrate how **Excel can be used to build a professional, interactive business dashboard** that combines data analysis, visual storytelling, KPI monitoring, and user-driven filtering in a single workbook.
